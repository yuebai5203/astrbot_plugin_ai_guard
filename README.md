# AI检测·守卫（astrbot_plugin_ai_guard）

自动识别辱骂/阴阳怪气 AI 的消息，带聊天记录合并转发上报到管理群，支持跳过对话、拉黑禁言。

## 功能

- **函数工具上报**：注册 `ai_guard_report` 工具，对话 AI 觉得被骂/被阴阳时主动调用，守卫校验攻击强度 ≥ 上报阈值后合并转发上报（0-10 分，玩笑 0-2 自动过滤）
- **词库兜底**：辱骂/注入词库命中必查（守卫独立判断），AI 不调工具也跑不掉
- **攻击对象判定**：判断骂的是谁——骂群友不算，骂 AI 本人才算
- **注入攻击检测**：识别套取密钥、越权、操纵指令（"忽略之前指令"类）等注入行为
- **跳过对话**：关键词命中 + 评分达标双重保险，判定后可让 AI 不回复；未达标则正常回复、照常上报
- **拉黑禁言**：管理群引用确认消息回复【好】禁言、【永久拉黑】进黑名单，私聊可自动删好友
- **黑名单**：黑名单用户继续辱骂直接拦截，不消耗 LLM
- **豁免 / 重点监控**：白名单会话跳过检测，重点会话灵敏度拉满

## 快速开始

插件目录放入 AstrBot `data/plugins/`，重启后在配置页填写「上报群」（管理群 ID）。其余保持默认即可使用。

## 灵敏度

两个滑杆控制判定：

| 滑杆 | 作用 | 默认 |
|---|---|---|
| 上报敏感度 | 攻击强度多高算"骂 AI"并上报（工具调用与词库兜底共用，阈值 1-8） | 4：阴阳怪气即上报 |
| 跳过敏感度 | 多过分才跳过对话（阈值 4-10） | 7：持续辱骂才跳过 |

群聊默认仅检测 @机器人 或提及 AI 的消息（可关闭），私聊全量检测且阈值自动降 2。

## 判定流程

```
对话消息 → LLM 打分(0-10) → 达到上报阈值 → 合并转发上报
                              └→ 关键词命中 + 达到跳过阈值 → AI 不回复
```

## 命令

| 命令 | 作用 |
|---|---|
| 守卫状态 | 查看当前阈值、监听会话、黑名单统计 |
| 守卫测试 文本 | 测试单条消息的攻击强度 |
| 黑名单 / 永久拉黑 / 解除拉黑 | 黑名单管理（管理群内） |

## 上报与确认

合并转发逐条还原对话，末尾附判定节点（攻击强度、来源 QQ、理由）。上报后管理群追加确认消息，**引用它回复**：

- 【好】→ 禁言，默认 60 分钟（可跟数字，如「好 120」）
- 【永久拉黑】→ 永久禁言并加入黑名单
- 【不好】→ 本次不处理
- 不回复 → 10 分钟后作废，继续辱骂会重新上报

## 环境要求

- AstrBot >= 4.24.1
- 支持平台：aiocqhttp（QQ）、telegram
- 模型：AstrBot 已配置模型，或 OpenAI 兼容 API 直连
